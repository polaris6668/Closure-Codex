# 让桌宠跟随 Codex、DSH 和 WorkBuddy

双击完整包里的 `Install.cmd` 启动桌宠，右键勾选你使用的软件。第一次安装时，三个联动开关都关闭，可以按需同时开启。

## Codex

勾选「Codex 联动」，然后在本机 Codex 中开始一段对话。桌宠会响应任务开始、完成、提问和工具出错等事件。用鼠标中键点桌宠可查看账号提供的剩余额度、积分或已适配服务的余额。

## DSH

1. 在完整包的 `plugins/dsh-companion` 文件夹找到 `dsh-closure-companion-bridge-0.1.2.tgz`。这是负责桌宠联动的插件，主题插件在另一个文件夹。
2. 打开 DSH 自带的终端，保存工作并从托盘退出 DSH。在该终端执行下面的命令，把引号里的路径换成实际文件路径。

```powershell
dsh plugin --profile desktop add "C:\Downloads\dsh-closure-companion-bridge-0.1.2.tgz"
```

3. 重新打开 DSH，右键桌宠，勾选「DSH 联动」。把鼠标移到桌宠上，按一下滚轮即可分别查看官方钱包的充值余额和赠送余额。

## WorkBuddy

1. 首次连接前保存工作，从任务栏右下角的托盘退出 WorkBuddy。
2. 想同时用主题，双击 `Enable-WorkBuddy-Theme.vbs`。只想让桌宠跟随任务，就双击 `Start-WorkBuddy-Companion.vbs`。以后也用自己选的文件启动。
3. 右键桌宠，勾选「WorkBuddy 联动」。把鼠标移到桌宠上，按一下滚轮即可查看当前账号的剩余积分，支持不限量账号。

## 多个对话同时工作时

比如 Codex 正在写代码，DSH 先问了你一个问题，桌宠就会显示 DSH 的提示。接下来 Codex 又输出内容或完成任务，桌宠会转回 Codex。同一软件里的多个对话也按这个规则处理。余额刷新不会打断当前提示，切换后会跳过旧提示。

三个软件共用你选择的台词，切换时会接着原来的顺序轮换。想让桌宠只出现在联动软件的窗口里，可取消「在桌面和其他软件中显示」。三项联动全关时，这个选项会让桌宠只跟随 Codex 窗口。

## 看不到余额时

- 用鼠标中键（按下滚轮）点桌宠，左键用于听台词。余额只在手动查看时弹出，已连接的软件会分别列出。
- 气泡缺少某款软件时，检查该软件的联动开关及启动步骤。软件已连接但尚未登录或查询失败时，气泡会显示对应状态。
- DSH 查询官方钱包，WorkBuddy 查询软件账号积分。第三方模型或中转服务的余额只在 Codex 已适配该服务时可查。

DSH 和 WorkBuddy 联动只在本机传递任务状态、用量和余额。联动记录不保存对话正文、工具参数或登录凭据。已适配的版本为 DSH `0.2.2-rc.5` 与 WorkBuddy `5.11.3`。
